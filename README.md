开挖要找内核、写配置；跑起来还要盯算力、查掉线、看温度。**疯狂的珍珠把这些日常操作收在同一个界面里。** 选好内核，填好收款账户和矿池，就能开始管理矿机。参数自动保存，下次打开继续用。

## 为什么用疯狂的珍珠

| 多卡看得清 | 异常有人管 | 调校有依据 |
| :--- | :--- | :--- |
| 总算力与每张卡的状态同时查看。掉速的是哪张卡、温度高在哪里，一眼定位。 | 低算力、长时间没有接受份额、温度过高，都能设置处理规则；重启次数也有上限。 | 读取驱动支持的频率档位，再选择目标组合；功率、风扇和频率集中管理。 |

**少切窗口，少翻脚本，矿机的运行状态更容易掌握。**

## 功能一览

| 功能 | 能帮你做什么 |
| :--- | :--- |
| **多内核中心** | 支持 SRBMiner-MULTI、PeakMiner、BzMiner。说明卡片、官方版本下载、完整目录导入集中在一处，方便选择和切换。 |
| **多显卡监控** | 逐卡查看算力、GPU 核心温度、显存温度、功耗、风扇、频率和份额。长表独立滚动，调校目标按设备身份保存。 |
| **显卡直接调校** | NVIDIA 显卡可调整功率、风扇及频率；独立按钮读取驱动频率档位，支持立即应用或开挖时应用。 |
| **保护与自动恢复** | 设定低算力、无接受份额及温控规则，配合暖机时间和一定时间内的重启次数限制，处理运行异常。 |
| **本地算力趋势** | 按内核汇报更新，时间范围可选分钟、小时、日；断档标红并记录日志，方便回看掉速和断线。 |
| **收益与用电估算** | 自选交易所和价格口径，结合算力、电价、功耗与运行时长，查看实测折算日净收益、电费和理论对照。支持人民币、美元。 |
| **矿池与启动管理** | 自填收币地址、矿池账户和矿工名，配置备用矿池；可选开机自动挖矿，使用已保存的参数启动。 |
| **日志与诊断** | 内核实时输出检索、软件日志查看和诊断导出。日志集中存放，按七天保留规则自动清理。 |

温度、频率等读数来自内核或驱动；未提供的数据会在界面标明。显卡支持范围以所选内核为准，直接调校功能面向 NVIDIA 显卡。

## 快速上手

### ① 下载，放进同一个文件夹

首次使用请下载下面三个文件，放进一个**可写文件夹**。无需解压，显卡驱动请提前安装。

| 文件 | 下载 | 用途 |
| :--- | :---: | :--- |
| **疯狂的珍珠-0.2.13.exe** | [下载程序](./疯狂的珍珠-0.2.13.exe?raw=true) | 主程序 |
| **settings.json** | [下载配置](./settings.json?raw=true) | 空白初始配置，使用后自动保存参数 |
| **fee-ledger.json** | [下载计时文件](./fee-ledger.json?raw=true) | 初始累计计时 |

也可以从仓库文件页面点击 **Download raw file** 下载。README 可一并保存，方便离线查看。

### ② 选内核，填收款信息

打开 EXE，进入 **内核中心**，下载并选用内核；已有内核可导入完整目录。然后回到 **运行总览**，填写：

| 参数 | 怎么填 |
| :--- | :--- |
| **收币地址 / 矿池账户** | 填自己的 PRL 收币地址，或矿池要求的账户。 |
| **矿工名** | 给这台矿机起一个便于识别的名字。部分矿池使用 `账户.矿工名`，点号后的名称需在收币账户框修改。 |
| **矿池地址** | 按矿池提供的 `域名:端口` 填写；备用连接及账户规则按所选内核说明设置。 |

> **请先填自己的收款信息。地址留空开挖时，程序会使用作者地址，相关收益归作者；运行总览会给出提示。**

### ③ 开始挖矿，再补好运行规则

点击 **开始挖矿**，在总览查看算力、温度和接受份额。有效参数修改后自动保存，无需反复点击保存。

- **长期运行**：进入“保护与恢复”，填写低算力、无份额、温控和重启次数规则。
- **需要调卡**：进入“显卡调校”，先“读取驱动频率档位”，选择目标后“立即应用”，或启用开挖时应用。
- **查看收益**：进入“收益计算”，选择交易所，填写电价、汇率和其他估算参数。

发布配置中的账户、矿工名、设备调校和累计计时均为空白；电价及算力、功耗估算项已清零，请按实际情况填写。

## 常用设置

<details>
<summary><strong>自动恢复：让规则接管掉速和无份额</strong></summary>

例如：算力连续 **5 分钟**低于基准的 **10%** 时重启内核，**15 分钟**内最多重启 **3 次**。这是填写示例，可按设备情况调整。

无接受份额、暖机和温控规则也可分别设置；配合本地趋势和软件日志，能回看异常出现的时间及处理记录。

</details>

<details>
<summary><strong>显卡调校：先读驱动档位，再应用目标</strong></summary>

“读取驱动频率档位”会列出驱动支持的频率组合，方便选择。编辑参数会保存目标，点击应用后才修改硬件；核心或显存频率为 **0** 时使用自动模式。

多张显卡分别保存调校目标，按设备身份对应，便于独立管理。

</details>

<details>
<summary><strong>备用矿池与开机自动挖矿</strong></summary>

在矿池设置中加入备用连接，并核对所选内核的收款账户、密码和连接规则。

需要开机自动挖矿时，先确认自己的收款账户和矿池已保存，再到“保护与恢复”启用。下次启动会读取已保存的配置。

</details>

<details>
<summary><strong>收益计算：把电费和实际运行情况一起算</strong></summary>

选择交易所及买一、最新成交等价格口径，填写电价、USDT 折人民币、其他用电、每日运行时长和综合扣减比例。页面会折算日收益和用电成本，也可切换人民币、美元显示。

日收益是按所选行情和输入参数得到的估算值；用于比较设备、参数和用电成本时，请保持统计口径一致。

</details>

## 目录与升级

<details>
<summary><strong>程序、配置和日志都在软件目录里</strong></summary>

```text
疯狂的珍珠/
├─ 疯狂的珍珠-0.2.13.exe
├─ README.md
├─ settings.json       自动保存的配置
├─ fee-ledger.json     累计计时
├─ logs/               运行日志
├─ kernels/            下载或导入的内核
└─ downloads/          下载缓存
```

三个文件夹会在首次使用时自动创建。日志保留今天和此前六天，正在写入或被占用的文件延后清理；配置和累计计时长期保留。

**升级时**：先停止挖矿并退出，保留原来的 `settings.json`、`fee-ledger.json` 和 `kernels/`，再替换新版 EXE。不要用初始空白配置覆盖正在使用的配置。

</details>
