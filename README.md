# 疯狂的珍珠 · PRL 自动超频与节能挖矿

**同一张显卡，换一组参数，可能用更少的电跑出相近甚至更高的算力。** 疯狂的珍珠把这件事做成了逐卡自动测试：先测基线，再试核心超频偏移与功率组合，用实际算力和功耗评分，复测后保存方案。每张卡独立找参数，适合不同型号、不同体质的 NVIDIA 显卡。

## 一次调优带来了什么

RTX 5070 Ti 的一次 PRL 本地测试：

| 指标 | 调优前基线 | 确认的能效方案 | 变化 |
| :--- | ---: | ---: | ---: |
| **GPU 平均功耗** | 279.82 W | **249.98 W** | **降低 10.7%** |
| **本地平均算力** | 177.03 TH/s | **178.77 TH/s** | **提升 1.0%** |
| **GPU 每瓦算力** | 0.633 TH/s/W | **0.715 TH/s/W** | **提升 13.0%** |

**这次测试中，功耗少了约30W，算力仍略有提升。** 方案为核心偏移 +120 MHz、功率上限250W；基线功率上限280W。基线测量180秒，候选方案复测600秒，复测期间矿池接受16个份额。

<details>
<summary>测试条件与统计口径</summary>

示例来自0.2.18自动调优测试；当前0.2.19加入多卡适配改进。内核 SRBMiner-MULTI 3.7.3，NVIDIA 驱动617.42；两组设置均保持显存目标7001 MHz、风扇100%。算力取本地内核汇报，功耗取驱动读数，能效按测量窗口内累计算力与能耗计算。表中百分比使用未舍入的数据计算。

数据代表这张显卡在上述条件下的表现，其他设备、内核和环境需独立测试。GPU功耗不含主板、CPU及电源转换损耗；整机用电可在收益计算中另行计入。

</details>

## 为什么用疯狂的珍珠

| 每瓦算力优先 | 每张卡单独找参数 | 找好之后，继续稳定跑 |
| :--- | :--- | :--- |
| 选择“最高能效”，在保留所设最低算力的前提下比较功耗；需要冲算力时可切换“最高算力”。 | 按物理设备逐卡测量和保存方案，不把一张卡的参数直接套给整台矿机。 | 候选方案复测10分钟；支持取消恢复、温控、低算力重启和无份额恢复，配置自动保存。 |

超频与功率限制一起调，测试功率不超过开始时的上限。驱动不支持核心偏移时，软件只测试功率组合。

| 功能 | 能帮你做什么 |
| :--- | :--- |
| **逐卡自动调优** | 测试每张 NVIDIA 显卡的实际算力与功耗，分别保留最高算力和最佳 GPU 能效；支持取消回退和保存确认方案。 |

| **多显卡监控** | 逐卡查看算力、GPU 核心温度、显存温度、功耗、风扇、频率和份额。长表独立滚动，调校目标按设备身份保存。 |
| **显卡直接调校** | NVIDIA 显卡可调整功率、风扇及频率；独立按钮读取驱动频率档位，支持立即应用或开挖时应用。 |
| **保护与自动恢复** | 设定低算力、无接受份额及温控规则，配合暖机时间和一定时间内的重启次数限制，处理运行异常。 |
| **本地算力趋势** | 按内核汇报更新，时间范围可选分钟、小时、日；断档标红并记录日志，方便回看掉速和断线。 |
| **收益与用电估算** | 自选交易所和价格口径，结合算力、电价、功耗与运行时长，查看实测折算日净收益、电费和理论对照。支持人民币、美元。 |

| **日志与诊断** | 内核实时输出检索、软件日志查看和诊断导出。日志集中存放，按七天保留规则自动清理。 |

温度、频率等读数来自内核或驱动；未提供的数据会在界面标明。显卡支持范围以所选内核为准，直接调校功能面向 NVIDIA 显卡。

## 快速上手

### ① 下载，放进同一个文件夹

首次使用请下载下面三个文件，放进一个**可写文件夹**。无需解压，显卡驱动请提前安装。

| 文件 | 下载 | 用途 |
| :--- | :---: | :--- |
| **疯狂的珍珠-0.2.19.exe** | [下载程序](./疯狂的珍珠-0.2.19.exe?raw=true) | 主程序 |
| **settings.json** | [下载配置](./settings.json?raw=true) | 空白初始配置，使用后自动保存参数 |
| **fee-ledger.json** | [下载份额账本](./fee-ledger.json?raw=true) | 初始份额账本 |

也可以从仓库文件页面点击 **Download raw file** 下载。README 可一并保存，方便离线查看。

### ② 选内核，填收款信息

打开 EXE，可先在右上角选择语言，再进入 **内核中心**，下载并选用内核；已有内核可导入完整目录。然后回到 **运行总览**，填写：

| 参数 | 怎么填 |
| :--- | :--- |
| **收币地址 / 矿池账户** | 填自己的 PRL 收币地址，或矿池要求的账户。 |
| **矿工名** | 给这台矿机起一个便于识别的名字。部分矿池使用 `账户.矿工名`，点号后的名称需在收币账户框修改。 |
| **矿池地址** | 按矿池提供的 `域名:端口` 填写；备用连接及账户规则按所选内核说明设置。 |

> **请先填自己的收款信息。地址留空开挖时，程序会使用作者地址，相关收益归作者；运行总览会给出提示。**

### ③ 开始挖矿，再补好运行规则

点击 **开始挖矿**，在总览查看算力、温度和接受份额。有效参数修改后自动保存，无需反复点击保存。

- **长期运行**：进入“保护与恢复”，填写低算力、无份额、温控和重启次数规则。
- **需要调卡**：进入“显卡调校”，先“读取驱动频率档位”，选择目标后“立即应用”，或启用开挖时应用。
- **自动找参数**：开挖稳定后，在“显卡调校”勾选要测试的在线 NVIDIA 显卡，选择“最高能效”或“最高算力”，点击“开始自动调优”。多卡逐张测试，每轮暖机60秒、测量180秒，候选方案复测10分钟；确认后自动保存。测试功率不超过开始时的上限，“取消并恢复”可回到测试前参数。
- **查看收益**：进入“收益计算”，选择交易所，填写电价、汇率和其他估算参数。

发布配置中的账户、矿工名、设备调校和份额账本均为空白；电价及算力、功耗估算项已清零，请按实际情况填写。

## 常用设置

<details>
<summary><strong>自动恢复：让规则接管掉速和无份额</strong></summary>

例如：算力连续 **5 分钟**低于基准的 **10%** 时重启内核，**15 分钟**内最多重启 **3 次**。这是填写示例，可按设备情况调整。

无接受份额、暖机和温控规则也可分别设置；配合本地趋势和软件日志，能回看异常出现的时间及处理记录。

</details>

<details>
<summary><strong>显卡调校：先读驱动档位，再应用目标</strong></summary>

“读取驱动频率档位”会列出驱动支持的频率组合，方便选择。编辑参数会保存目标，点击应用后才修改硬件；核心或显存频率为 **0** 时使用自动模式。

多张显卡分别保存调校目标，按设备身份对应，便于独立管理。

</details>

<details>
<summary><strong>备用矿池与开机自动挖矿</strong></summary>

在矿池设置中加入备用连接，并核对所选内核的收款账户、密码和连接规则。

需要开机自动挖矿时，先确认自己的收款账户和矿池已保存，再到“保护与恢复”启用。下次启动会读取已保存的配置。

</details>

<details>
<summary><strong>收益计算：把电费和实际运行情况一起算</strong></summary>

选择交易所及买一、最新成交等价格口径，填写电价、USDT 折人民币、其他用电、每日运行时长和综合扣减比例。页面会折算日收益和用电成本，也可切换人民币、美元显示。

日收益是按所选行情和输入参数得到的估算值；用于比较设备、参数和用电成本时，请保持统计口径一致。

</details>

## 目录与升级

<details>
<summary><strong>程序、配置和日志都在软件目录里</strong></summary>

```text
疯狂的珍珠/
├─ 疯狂的珍珠-0.2.19.exe
├─ README.md / README.en.md / README.fr.md  可选的本地指南
├─ settings.json       自动保存的配置
├─ fee-ledger.json     份额账本
├─ logs/               运行日志
├─ kernels/            下载或导入的内核
└─ downloads/          下载缓存
```

三个文件夹会在首次使用时自动创建。日志保留今天和此前六天，正在写入或被占用的文件延后清理；配置和份额账本长期保留。

**升级时**：先停止挖矿并退出，保留原来的 `settings.json`、`fee-ledger.json` 和 `kernels/`，再替换新版 EXE。不要用初始空白配置覆盖正在使用的配置。

</details>

<details>
<summary><strong>逐卡自动调优</strong></summary>

先开始挖矿，在“显卡调校”勾选要测试的显卡，向下找到自动调优。选择最高能效或最高算力，填写算力下限和核心偏移上限，然后开始测试。请只保留一个显卡调校控制程序。

默认保留至少 90% 基线算力，核心偏移上限 +180 MHz。每轮暖机 60 秒、测量 180 秒，候选复测 10 分钟，多卡顺序测试。确认方案会保存并继续应用；下次开挖是否应用，由原有“开始挖矿时应用”选项决定。

测试不提高开始测试时的功率上限。驱动支持时探索核心偏移、功率及附近组合；不支持偏移时只测试功率。显存保持基线设置，电压不调整。取消、过热、掉卡或异常触发回退，回退失败则停止本软件矿工。接受份额采用进程汇总计数，不单独证明每张卡都提交过份额。

能效按逐卡 GPU 的 TH/s/W 计算，整机电费另需计入主板和电源损耗。结果代表当前设备、内核和测试范围内的表现；更换内核或驱动后建议重新测试。详细记录位于 `logs/日期/auto-tune-*/report.json`，随日志保留七天。

</details>
