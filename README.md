# 疯狂的珍珠｜让 PRL 挖矿更省心：多内核、显卡调校与自动恢复

**CrazyPearl · PRL Mining Manager · Windows x64 · v0.2.13**

开挖前要配内核、填矿池、设显卡；开挖后还要看算力、盯温度、查断线。疯狂的珍珠把这套流程收进一个 Windows 窗口。填好自己的收币账户、选好内核，就能在同一处完成监控、调校和恢复设置。

功能围绕矿机每天要做的事来安排：单卡掉速有规则接管，输出断档有记录可查，参数修改会自动保存，多张显卡也能分别管理。少折腾启动脚本，多看得见运行状态。

## 好用在哪里

| 你要做的事 | 疯狂的珍珠怎么处理 |
| --- | --- |
| 选择内核 | SRBMiner-MULTI、PeakMiner、BzMiner，提供官方版本下载、完整目录导入和说明卡片，切换前就能看清区别。 |
| 看矿机状态 | 逐卡显示算力、GPU 核心温度、显存温度、功耗、风扇、频率及份额；内核或驱动未提供的读数会标明。 |
| 管好多张卡 | 总览和调校按设备分别显示，长表可以独立滚动，目标参数按设备身份保存。 |
| 调功率和频率 | NVIDIA 显卡可直接调校；独立按钮读取驱动支持的频率档位，选好组合再应用。 |
| 处理异常 | 低算力、长时间没有接受份额、温度过高等情况可设置处理规则，并限制一定时间内的重启次数。 |
| 查断线和掉速 | 本地趋势按内核汇报更新，时间范围可选分钟、小时、日；断档标红，原因写入日志。 |
| 估算每天收益 | 选择交易所和价格口径，填电价、功耗、运行时长等参数，查看实测折算日净收益、电费及理论对照，支持人民币和美元。 |

配置有效修改后自动保存。可选开机自动挖矿，按已保存的账户和矿池启动；支持备用矿池、实时输出检索、日志查看及诊断导出。

## 五步开始挖矿

1. **下载程序和配置**：分别下载仓库根目录的 EXE、settings.json 和 fee-ledger.json，放进同一个可写文件夹，再打开 EXE。文件页面点击「Download raw file」下载，无需解压；README 可一并保存。先安装好显卡驱动。
2. **选择内核**：进入“内核中心”，查看说明卡，下载并选用内核；已有内核也可以导入完整目录。
3. **填写收款和矿池**：在“运行总览”填写自己的收币地址或矿池账户、矿工名和矿池地址。部分矿池使用“账户.矿工名”，点号后的名称在收币账户框修改；备用矿池的账户规则按内核说明填写。
4. **开始挖矿**：点击“开始挖矿”，查看算力和接受份额。之后的有效参数修改会自动保存。
5. **补好运行设置**：到“保护与恢复”填写恢复规则；需要调卡时先“读取驱动频率档位”，选好目标，再点击“立即应用”或启用开挖时应用。在“收益计算”填自己的电价、汇率和估算参数。

**首次开挖请填写自己的收币地址或矿池账户。地址留空时，程序会使用作者地址，相关收益归作者；运行总览会给出提示。**

发布包的账户、矿工名、设备调校和累计计时均为空白。电价及算力、功耗估算项已清零，请填写后再使用收益估算。

## 几个常用设置

- **自动恢复**：例如设为算力连续 5 分钟低于基准的 10% 时重启内核，并设置 15 分钟内最多重启 3 次；无接受份额、暖机和温控规则也可分别填写。
- **频率控制**：先读取驱动档位，再选择目标组合。编辑只保存目标，应用后才修改硬件；核心或显存频率为 0 时使用自动模式。
- **备用矿池**：在矿池设置中加入备用连接，并核对该内核的收款账户与密码规则。
- **开机自动挖矿**：先填好自己的账户并确认有效配置已保存，再在“保护与恢复”中启用。
- **收益口径**：可选交易所、买一或最新成交价，补入电价、其他用电和综合扣减比例。页面中的日收益是按这些输入折算的估算值。

## 文件都在软件目录里

```text
疯狂的珍珠-0.2.13.exe
README.md
settings.json       自动保存的配置
fee-ledger.json     累计计时
logs/               运行日志
kernels/            下载或导入的内核
downloads/          下载缓存
```

logs、kernels、downloads 文件夹会在首次使用时自动创建。日志保留今天和此前六天，正在写入或被占用的文件延后清理。配置和累计计时长期保留。

升级时先停止挖矿并退出，保留原来的 settings.json、fee-ledger.json 和 kernels 目录，再替换新版 EXE。不要用发布包的空白配置覆盖正在使用的配置。
